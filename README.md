# Metrics Analyzer

Metric Intelligence Platform. This repository is the frontend demonstration.

The current screens use an in-app mock of the metric register. They are not connected to SMARTS, Snowflake, or Cortex. Readings shown in the demo are labelled illustrative unless a scenario fact says otherwise.

```bash
npm install
npm run dev
```

`/` opens the Dashboard. `/overview` is the detailed monitoring view. `/metrics` is the register.
